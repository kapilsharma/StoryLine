The first icon on a card is its **status** — where the scene stands, e.g. **💡** idea, **🌓** draft started, **✅** draft done. Hover it to see what it means. Pick a status from the **Status** dropdown when the note is open (popup or side panel); the list itself is set in **Settings → Card statuses**.

**📝** — the note has a body, not just a title. **🔗** — the note has related links. **⤢** — the title is too long for the card and can be expanded.

Card text size follows the **Card font size** setting and scales with the board zoom.
