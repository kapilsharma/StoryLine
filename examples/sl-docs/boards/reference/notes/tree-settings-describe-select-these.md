**Tree settings** opens the panel: **Centred on**, **Parent depth**, **Child depth**, and a checkbox for spouses' families. Depths left blank mean "all".

**Select these** replaces the tree's people with whoever the filters describe. To add individuals instead, use the add control in the toolbar.
