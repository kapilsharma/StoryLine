title: Copying a note file copies its uid
boards:
  - reference
tags:
  - notes
  - files
created: '2026-08-17'

Duplicating a note by copying the file gives two notes the same uid, and a card may then resolve to either.

Delete the `uid:` line from the copy and let the app assign a fresh one.
