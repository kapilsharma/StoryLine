The **⤢** appears only when a title is long enough to be truncated, so most cards will not have one. That is not a bug. The same goes for row names: widen the header column and a button can disappear, because the name now fits.

Card text scales with zoom, so shrinking the board also shrinks the text — set the base size under **Card font size** in Settings.
