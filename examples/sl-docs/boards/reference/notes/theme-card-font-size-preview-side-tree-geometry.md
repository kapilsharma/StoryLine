These are app preferences, stored outside any project, so they follow you between projects rather than travelling with one — including whether a board note opens as a popup or in a side panel.

Theme, card font size, image card height and title position, and the note view are under **General**; preview side and word count under **Editor**. The **Family tree** category sets node width and height, generation, sibling and partner gaps, and node font size. It is hidden on a *general* project, like the Family tab.
