title: Auto-save means no undo history across sessions
boards:
  - reference
tags:
  - editor
created: '2026-08-17'
---
Changes are written as you go, so closing the editor is not a decision point. Your editor-level undo works within a session; there is nothing to roll back to afterwards.

If a note matters that much, keep the project under version control.
