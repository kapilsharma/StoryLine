The confirmation says so, and the tooltip repeats it: a timeline tree cannot go back to free-flowing. Duplicate the tree first if you want to keep both.

The **problems** button reports data issues — a dangling parent id, a one-sided spouse, a cycle. It reports; it never refuses to draw.
