title: Zoom is saved; expansion is not
boards:
  - reference
tags:
  - board
created: '2026-08-17'
---
The zoom level is stored per board, so a board you like at 80% opens at 80% next time. The width of the row-header column is stored the same way, per board.

What is expanded is per session — a fresh open starts with every card and every row name collapsed.

Unlike zoom, the header width is not scaled by it: zoom decides how much of the plot fits on screen, and the names stay readable either way.
