Standard Markdown with GitHub extensions — tables, task lists, strikethrough — plus `==highlight==`, syntax-highlighted code fences, footnotes, and `[[wiki-links]]`.

Tables are drawn with borders and left-aligned headers. Put a colon in the divider row to align a column — `:---:` centres it, `---:` right-aligns it:

| Colour | Meaning |
|--------|---------|
| Blue   | School |
| Red    | Fixed — exams, appointments, family trips |

Math (KaTeX and friends) is deliberately not included.
