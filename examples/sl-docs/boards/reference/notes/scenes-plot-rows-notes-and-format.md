**Scenes** walks the column tree (Novel ▸ Part ▸ Chapter ▸ Scene), each tier's own note underneath. **Plot rows** lists each plot thread's cards in column order.

Turn **Note bodies** off for a bare outline of headings. **PDF** is for printing; **Markdown** stays editable.
