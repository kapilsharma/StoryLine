The character form has a **Group** field. Everything with the same text lands in the same group.

Click a row group's heading to collapse or expand it. Drag a heading to move the whole group; drag a row header to move that row within its group.

Columns do not use a text field: a column sits **Inside** a group that you create on the Timeline tab. See *Columns can be grouped*.
