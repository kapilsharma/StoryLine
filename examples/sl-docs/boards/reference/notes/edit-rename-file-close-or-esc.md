**Edit** — **⤢ Editor** in the panel — opens the fullscreen editor. **Rename file** changes the note's filename, safely, because cards do not depend on it.

**Esc**, the **✕**, **Close**, or clicking outside all dismiss the popup. The panel closes on the **✕** or on **Esc** once no block is open, since the first **Esc** renders the block you were editing. The footer shows which file you are looking at.
