- **File** — New Project (**Ctrl+N**), Open Project (**Ctrl+O**), Open Recent, Back to Projects, Export Board, Publish Static Site, Settings (**Ctrl+,**).
- **View** — show or hide the Manuscript, plot and character rows; collapse or expand row and column groups; expand all cards; Filters (**Ctrl+Shift+F**); Word Count (**Ctrl+Alt+W**); Zoom In / Out / Actual Size (**Ctrl+=**, **Ctrl+-**, **Ctrl+0**).
- **Board** — new, rename or delete a board; add a column or row; save a preset; Revision Mode.
- **Go** — jump to a tab: Boards **Ctrl+1** through Notes **Ctrl+5**.
- **Help** — the user guide, reporting an issue, release notes, About.

On a Mac it is **Cmd** instead of **Ctrl**.
