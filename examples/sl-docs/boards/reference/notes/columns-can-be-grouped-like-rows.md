A **group** collects columns under a spanning heading on the board — parts, acts, seasons, novels — that can be collapsed to a single slot. Groups nest, so a board can have one heading row per level in use; a project that uses a single level has none.

Every group has a note, written in the same editor as any other, and opened by clicking its name on the board. Renaming a group never detaches its note: the group is a file with its own id (`colgroups/<id>.md`), and the columns point at that, not at its name.

A column can sit at any depth. A chapter with no scenes can sit beside a part that has them.

Tags are free-form and searchable from the Notes tab.
