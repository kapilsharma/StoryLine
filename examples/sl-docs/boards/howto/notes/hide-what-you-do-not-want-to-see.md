Right-click a row header → **Hide row**. Right-click a column header to hide it outright.

Once a board has plot rows, two toggles appear in the board toolbar: **📋** hides every plot row and **👥** hides every character row — so you can drop to a structure-only or character-only view in one click. The choice is remembered per board.
