A view holds `members` (who is drawn), the filters that seeded them (`root`, `parentDepth`, `childDepth`, `includeSpouseFamilies`, `hidden`), the mode (`freeflow` or `timeline`), and the display state: `zoom`, `panX`, `panY`, `collapsed`, `showGhosts`.

`overrides` stores hand-moved positions per character; `edgeRoutes` stores hand-bent connector waypoints. `arranged: true` means the tree has been shaped by hand and is frozen against re-layout.
