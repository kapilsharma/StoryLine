```json
{
  "schemaVersion": 3,
  "name": "My Novel",
  "timelineLabel": "Chapter",
  "rowLabel": "Character",
  "kind": "story",
  "boards": ["main", "subplot"],
  "created": "2026-01-04",
  "lastOpened": "2026-08-17",
  "families": { "Harker": "#3B6FD4" }
}
```

`boards` is the tab order. `families` holds the colour assigned to each surname on the family trees, so a family's colour stays stable as people are added.
