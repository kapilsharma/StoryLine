Being in the project and being a row are different things — deliberately, so a grandparent added for a family tree does not become a plot line.

A character created from the **Characters** tab stays off the grid. Put them on with the **Add character…** dropdown in the board toolbar, which only appears when someone is off-board. A character created with **+ Row** skips all this and lands on the board.
