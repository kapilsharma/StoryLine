Clicking a card opens its note in a popup — enough to read it and follow its links.

For real writing use **Open in editor**: a fullscreen Markdown editor with a live preview, a formatting toolbar, and title and tag fields. It saves as you type.

If you would rather read and write in one place, Settings can open notes in a panel beside the board instead — see *Popup or panel, your choice*.
