Settings shows the project's path under the save button. Open that folder: `project.json`, then `boards/<board>/` holding `board.json`, `characters/`, `timeline/`, `notes/` and `assets/`.

Every `.md` file is a plain Markdown file with a small YAML header. Open one in any editor.
