Open the **Settings** tab. **Column label** renames the Timeline tab ("Chapters", "Scenes", "Sections"); **Row label** renames the Characters tab ("Characters", "Topics", "Phases").

Set **Project kind** to *General* if your rows are not people. Press **Save project settings** — this one is not auto-saved.
