Open the **Settings** tab. **Column levels** names the levels of your columns, outermost first — just "Chapter", or "Part" › "Chapter", or "Novel" › "Part" › "Chapter" › "Scene". The last level names the Timeline tab ("Chapters", "Scenes", "Sections"). **Row label** renames the Characters tab ("Characters", "Topics", "Phases").

Set **Project kind** to *General* if your rows are not people. Press **Save project settings** — this one is not auto-saved.
